# LoryPublis – Web Layout Editor

Stack: Vite + React + TypeScript + Tailwind + lucide-react + react-rnd + html-to-image + jsPDF

## Deploy automatico su GitHub Pages (senza installare niente)
1. Crea su GitHub un repo (es: `LoryPublisApp`).
2. Carica dentro TUTTI i file di questa cartella (non lo zip intero) → *Upload files* → Commit su `main`.
3. Vai su **Actions**: parte il workflow **Deploy to GitHub Pages**. Al termine il sito è online.

URL atteso: `https://<username>.github.io/<repo>/`

## Test (facoltativi, in locale)
```bash
npm install
npm run test
```

## Build locale (facoltativa)
```bash
npm install
npm run dev
npm run build
```
